# LingoBuddies

Learning modules for adults and children.

## Modules

- **Petit Français** (`french-kids/`): an interactive French course for kids aged 6 to 9. Open `french-kids/petit-francais.html`. Every word has pre-recorded audio in two voices (`audio/` girl, `audio/boy/` boy). `make_audio.py` regenerates the clips with Kokoro.

The site is static: no build step. The root `index.html` opens the French module.
